## Flutter packages

Flutter/Dart package versions are constrained in `pubspec.yaml`. `pubspec.lock` is currently absent and should be generated, reviewed and committed after a successful application dependency resolution. Major roles include Riverpod (state), GoRouter (navigation), Drift/sqlite3 (history), file picker/path provider (platform storage), camera/image picker (scan capture), http/crypto (release check and checksums), and share/open plugins (results). Release bundles generated by Flutter include package notices in `NOTICES.Z`.

Only permissively licensed dependencies may be introduced. A change adding native code must record exact version, source URL, license, role, build flags, and full notice here and under `native/third_party/LICENSES`.

## Build and runtime qualification

PDFium, qpdf, HarfBuzz/FreeType, OpenCV, Mbed TLS, libwebp and libtiff are wired into the native CMake graph through discovery, pinned binary archives, FetchContent or vendored source. Tesseract/Leptonica remains optional and defaults off. The actual linked set is reported by `abz_build_features()`; wiring does not prove every Android ABI or Windows package contains a working module. Version upgrades require license review, binary-size/ABI checks and structural tests.
